# MGO USAR — Check-list opérationnelle

Site indépendant, responsive, utilisable sur ordinateur et smartphone.

## Fonctionnalités
- Cases à cocher par phase et suivi de progression.
- Champs de contexte et notes.
- Sauvegarde automatique locale dans le navigateur.
- Export des données de l'opération en JSON.
- Impression ou enregistrement en PDF via le navigateur.
- PWA installable et cache hors connexion après première ouverture en ligne.
- Aucune fonction d'envoi de courriel.

## Publication GitHub Pages
1. Créer un dépôt GitHub indépendant, par exemple `MGO-USAR`.
2. Décompresser cette archive et importer tous les fichiers, y compris le dossier `.github`.
3. Dans **Settings → Pages**, choisir **GitHub Actions** comme source si cela n'est pas déjà fait.
4. Le workflow publie automatiquement le site à chaque mise à jour sur `main`.
5. L'adresse sera de la forme `https://VOTRE-NOM.github.io/MGO-USAR/`.

## Données et confidentialité
Les données sont sauvegardées dans le stockage local du navigateur sur l'appareil utilisé. Elles ne sont pas synchronisées entre plusieurs appareils. Exporter le JSON pour conserver/transférer un dossier. Sur un appareil partagé, effacer les données après utilisation.

## Important
Aide-mémoire à adapter aux procédures locales et aux décisions du COS ; il ne remplace pas la doctrine opérationnelle.
